# FitQuest

FitQuest is a fitness tracking app built with Flutter and Firebase.
The goal of the project is to make fitness feel more engaging and interactive through step tracking, workout plans, diet suggestions, quests, streaks, and progress systems.

The app includes personalized health calculations based on user details like age, height, weight, BMI, and activity level.

---

## Features

* Daily step tracking
* Personalized calorie goals
* Workout recommendations
* Diet and meal suggestions
* XP, streaks, and quest system
* Firebase login and cloud storage
* Notifications and reminders

---

## Built With

### Frontend

* Flutter
* Dart

### Backend

* Firebase Authentication
* Cloud Firestore

### Other Services

* Google Sign-In
* Pedometer / Sensor APIs
* Flutter Local Notifications

---

## Running the Project

Clone the repository:

```
git clone https://github.com/zke-7D6/FitQuest.git
```

Go into the project folder:

```
cd FitQuest
```

Install dependencies:

```
flutter pub get
```

Run the app:

```
flutter run
```
